# Lit Protocol Skills

AI coding agent skills for [Lit Protocol](https://litprotocol.com). These skills give your agent knowledge of Lit's Flows platform — publishing, invoking, and paying for JavaScript functions running in Lit's TEE.

## Available Skills

| Skill | Description |
|-------|-------------|
| **flows** | Publish and consume paid JavaScript functions on Lit Protocol's TEE. Covers CLI usage, MCP setup, and payment via credits, x402, or MPP. |
| **flows-agent** | Discover and call paid web APIs (search, scraping, transcription, image gen, etc.) using a single Flows credit balance. No wallet, no per-provider keys. |

## Installation

Install a skill using `npx`:

```bash
npx skills add lit-protocol/skills --skill flows -g
```
